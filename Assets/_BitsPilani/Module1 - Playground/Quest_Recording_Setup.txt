QUEST RECORDING DESTINATION

Public headset folder: Internal shared storage / Movies / Quest
Quest Folder Name changes the final subfolder; the default is Quest.

Select M1 SYSTEMS - flow and audio / Module1 Playground Flow > PlaygroundSessionRecording.
- Save To Quest: enabled.
- Quest Folder Name: Quest.
- Keep Local Copy After Quest Save: disabled. Temporary source is removed only after successful verified publication/transfer. A failed or pending transfer always retains it.
- Output Folder: desktop staging folder for Quest Link. It remains unchanged from the user's configuration.
- ADB Executable: PC Android SDK/platform-tools/adb.exe. Needed for Link transfer only; APK never uses ADB.
- Quest Device Serial: optional for a single connected headset; required if multiple Android devices are connected.
- Send Pending Videos to Quest: retries finalized recordings that could not reach the headset.

APK ON QUEST
The MP4 is finalized in the app-writable staging directory and published through Android MediaStore to Movies/Quest. The public video stays outside the app's com.company... directory. No all-files storage permission is requested. Participant ID filenames and game audio are preserved. The same route is used for Finish Module, early scene exit and normal quit.

QUEST LINK ON PC
Link executes the Unity app on the PC. It must finalize locally first, then use ADB to copy to the connected headset's /sdcard/Movies/Quest. Enable Developer Mode and allow USB debugging in the headset. The receiving Android device is checked to be a Meta/Oculus Quest. Transfer size and SHA-256 checksums are verified before acknowledging and removing the temporary PC copy.
If the Quest is missing, unauthorized or transfer fails, the finished PC video and a .quest-transfer.json sidecar are retained. No headset-save success is reported. Reconnect and click Send Pending Videos to Quest. Editor Stop finalizes first, queues the transfer and retries in Edit Mode so copying does not delay native MP4 finalization.

VALIDATION LIMITS
No ADB device was connected when this change was implemented. PC recording, queue/error handling and destination validation can be tested locally. APK MediaStore publication and physical headset transfer require a connected Quest and remain device-test items. The project was not switched away from its Windows build target and no APK was installed automatically.

Normal app/scene exit can save a partial session. Force-killing the app, power loss or disconnecting the device during publication cannot guarantee completion; staging sources are retained when possible.
